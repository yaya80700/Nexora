# Nexora — V0.1

Première base de la plateforme Nexora, conçue pour être déployée sur Vercel.

## Lancer en local
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000

## Déploiement Vercel
Importer ce dossier/repository dans Vercel. La configuration Next.js est détectée automatiquement.

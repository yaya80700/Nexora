# Nexora V0.3

Plateforme Next.js avec :
- Accueil
- Formations + fiches individuelles dynamiques
- Nos sites / portfolio
- Nos services
- Contact avec formulaire côté interface
- Navigation réelle entre les pages
- Design responsive bleu/violet

## Lancer
npm install
npm run dev

## Vercel
Importez le dépôt GitHub dans Vercel. Next.js est détecté automatiquement.
Cette version conserve Next.js 15.5.24, le patch Maintenance LTS indiqué par Next.js pour la release de sécurité d'août 2026.
